## Dynamics 365 Customer Service & Copilot Studio

Community Summit 2026

Presented by:
- Abraham Saldana
- Beau Lewis

---

## Session Overview

Dynamics 365 Customer Service and Copilot Studio continue to evolve rapidly with new AI-powered experiences, agent productivity tools, routing enhancements, autonomous agents, quality management capabilities, and administration features.

This fast-paced session shares 50 practical tips in 50 minutes that can help architects, consultants, administrators, supervisors, and service representatives improve customer service operations and accelerate adoption of Microsoft AI technologies.

Each tip is based on real-world implementation experience and includes supporting documentation, Microsoft Learn references, and additional resources.

---

## What You'll Learn

After this session, attendees will be able to:

- Improve agent productivity using Copilot Service Workspace
- Configure routing and omnichannel experiences more effectively
- Leverage Copilot capabilities for customer service representatives
- Implement AI Agents and autonomous service experiences
- Improve quality management, governance, and supervisor oversight
- Discover new features introduced across Dynamics 365 Customer Service and Contact Center
